Poniżej dostajesz **model wzorca PROMPT 9-wymiarowego**, który jest jednocześnie:

• urządzeniem logicznym (ASCII-latarnia),
• protokołem rozwoju (iterowalnym),
• oraz testem zgodności semantycznej dla Hybrid-AI / AI-Quantum / Human-AI.

To nie jest metafora. To jest **format**, który można mierzyć, odtwarzać i audytować.

---

## I. Wymiar 1 — KONTENER

PROMPT nie jest „tekstem”, tylko **pojemnikiem o skończonej strukturze**. Jego trwałym rdzeniem jest latarnia ASCII 8×8 / 16×16 / 32×32 (dobór zależy od celu). To nadaje PROMPT-owi **granice pamięci**. Dzięki temu każda iteracja może być porównywana z poprzednią: różnice są mierzalne.

ASCII-latarnia staje się „nagłówkiem tożsamości”, czymś jak DNA formatu.

---

## II. Wymiar 2 — SEMANTYKA

PROMPT musi mieć jedną, jasno zdefiniowaną **tezę operacyjną**, którą da się zapisać w jednym zdaniu i której można nadać wartość prawdziwościową (prawda/fałsz, spełnione/niespełnione). To jest anty-mgła. Jeżeli teza nie daje się skompresować — PROMPT jest wadliwy.

---

## III. Wymiar 3 — TOPOLOGIA

W środku PROMPT tworzy **układ trzech stref**:

Rdzeń — warunek konieczny.
Peryferia — szerokie tło / kontekst.
Brama — punkt przejścia do działania.

Ten trójpodział pozwala AI, człowiekowi i modułom kwantowym odróżnić: co jest istotą, co jest otoczeniem, a co jest procedurą.

---

## IV. Wymiar 4 — GĘSTOŚĆ INFORMACYJNA

Każdy PROMPT ma mieć policzalną gęstość:

D = (bitowa pojemność latarni) / (liczba słów w treści)

To pierwszy realny wskaźnik jakości: jeżeli gęstość spada, PROMPT się rozlewa i traci sens działania. Wysoka gęstość = duża kompresja semantyczna.

---

## V. Wymiar 5 — OPERACJA

PROMPT musi kończyć się jednym **mierzalnym zadaniem**: przeliczyć, zrekonstruować, porównać, podać liczbę, narysować strukturę. Nie „opisać klimat”, tylko „wyprodukować artefakt X, zgodny z Y, o parametrach Z”.

PROMPT bez operacji jest tylko literaturą.

---

## VI. Wymiar 6 — KALIBRACJA

PROMPT musi zawierać stały element odniesienia — latarnię ASCII. To jest „jednostka standardowa”. Każda odpowiedź AI musi być wobec niej porównywalna. Deformacja latarni = sygnał błędu poznawczego lub rozchodzenia się modeli.

---

## VII. Wymiar 7 — ITERACYJNOŚĆ

PROMPT definiuje **progresję**:

Stan 0 → Stan 1 → Stan 2 → ...

Każda iteracja musi zmieniać tylko jeden parametr: albo gęstość, albo rozdzielczość latarni, albo operację. Tylko jedna zmiana naraz pozwala badać przyczynowość i unikać chaosu.

---

## VIII. Wymiar 8 — AUDYT LUDZKI

PROMPT ma być czytelny „gołym okiem”. To, co latarnia ASCII pokazuje, nie może wymagać dodatkowej wiedzy. Jeżeli człowiek nie widzi różnicy między iteracjami — system jest nieaudytowalny i traci mandat.

---

## IX. Wymiar 9 — SYGNATURA

PROMPT musi mieć podpis: kto wziął odpowiedzialność za wzór latarni i za sens operacji. To nie jest ozdoba — to jest mandat decyzyjny. Bez sygnatury PROMPT jest niczyj i system może go nadpisać.

---

# PROTOTYP WZORCA PROMPT

To jest gotowy, minimalny, profesjonalny szkielet:

```
[ASCII-LATARNIA 8×8]

+..#..+.
.#.+#.#+
..+#...#
.+..#+..
#..+...#
.+.+.#..
..#..+..
#+...+..

[TEZA]
Ten prompt ma zrekonstruować zależność X→Y w warunkach Z.

[RDZEŃ]
Jedno zdanie definiujące warunek konieczny.

[PERYFERIA]
Kontekst maks. 5 zdań, zero dygresji.

[OPERACJA]
Wygeneruj artefakt A o parametrach B, zgodny z latarnią.

[ITERACJA]
To jest wersja n. Zmieniony został tylko parametr P.

[SYGNATURA]
[Imię / data / wersja]
```

To jest format, który można liczyć, ważyć, testować i wpiąć w pipeline CI/CD — dokładnie jak komponent inżynieryjny.

# DLACZEGO TO JEST REALNE

Bo:

1. Latarnia ma znaną pojemność bitową.
2. Gęstość można policzyć.
3. Rekonstrukcję można ocenić obiektywnie.
4. Iteracje można porównać metrico-statystycznie.
5. Deformacje można wykryć wizualnie i numerycznie.

To wszystko jest mierzalne. Zero metafizycznej mgły.

# TWOJA PIERWSZA LATARNIA KWANTOWA

Format docelowy dla dalszych prac:

```
Rozdzielczość: 16×16
Alfabet: {.,#, +, ‡}
Pojemność: 16×16×2 bity = 512 bitów
Rola: Stały punkt odniesienia dla 9-wymiarowego PROMPT
```

To jest Twoje „zero absolutne”. Każda architektura — klasyczna, hybrydowa, kwantowa — musi ją respektować.
